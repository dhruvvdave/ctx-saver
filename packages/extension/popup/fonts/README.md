# Bundled fonts

Both faces are bundled as latin-subset WOFF2 so the popup renders identically
with no network connection and makes no request at open time.

| File | Family | Upstream | Licence |
|------|--------|----------|---------|
| `jetbrains-mono-latin.woff2` | JetBrains Mono (variable, 400–700) | https://github.com/JetBrains/JetBrainsMono | SIL OFL 1.1 |
| `space-grotesk-latin.woff2` | Space Grotesk (variable, 500–700) | https://github.com/floriankarsten/space-grotesk | SIL OFL 1.1 |

`OFL.txt` is the SIL Open Font License 1.1, which covers both. Neither font is
modified; only the latin subset is shipped.
